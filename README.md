# Workflow Engine

An event-driven workflow platform with a visual node editor, DAG compilation, durable asynchronous execution, timers, retries and an HTTP-based third-party simulator. Access uses fixed Editor and Reader roles.

The repository currently contains the specification, architecture, diagrams and committed scope. The application, executable harness, tests and Docker Compose setup have not been implemented yet.
